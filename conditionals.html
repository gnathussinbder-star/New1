B1 · GRAMMAR

جمل الشرط.

نعبّر بها عن الحقائق والاحتمالات والأحوال الخيالية. الأنواع الأساسية: zero وfirst وsecond وthird.

B1

متى نستخدمه؟

  • Zero: حقيقة دائمة — If you heat ice, it melts.
  • First: احتمال حقيقي في المستقبل — If it rains, we will stay home.
  • Second: موقف خيالي في الحاضر — If I were rich, I would travel.
  • Third: ماضٍ لم يحدث — If I had studied, I would have passed.
الصيغة

القاعدة

Zero: If + present, present
First: If + present, will + verb
Second: If + past, would + verb
Third: If + past perfect, would have + p.p.

جدول سريع

النوعالشرطالنتيجة

أمثلة مع النطق

اضغط على زر الصوت واستمع إلى الجملة، ثم كررها بصوت مرتفع.

  • If you study, you will pass.
    إذا درست فستنجح.
  • If I had more time, I would learn Spanish.
    لو كان لدي وقت أكثر لتعلمت الإسبانية.
  • If she were here, she would help.
    لو كانت هنا لساعدت.
  • If I had known, I would have called.
    لو كنت أعلم لاتصلت.
  • Water boils if you heat it to 100°C.
    يغلي الماء إذا سخّنته إلى 100 درجة.

أخطاء شائعة

✗ If it will rain, we stay home.
✓ If it rains, we will stay home.
بعد if في النوع الأول نستخدم المضارع لا will.
✗ If I was you, I would go.
✓ If I were you, I would go.
في النوع الثاني نفضل were مع كل الضمائر.
✗ If I would have time, I help.
✓ If I had time, I would help.
لا نضع would في جزء الشرط.

تحقق من فهمك

ثلاثة أسئلة قصيرة؛ اختر الإجابة وسيظهر لك الحكم فورًا.

If it ___ tomorrow, we will cancel the trip.

If I ___ you, I would apologize.

If he had left earlier, he ___ the train.
